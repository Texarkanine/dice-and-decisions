# Cannonball Rally

An illegal coast-to-coast street race from New York City to Redondo Beach. Racers pick a vehicle—ambulance, motorcycle, 4x4, SUV, supercar, or beige sedan—and burn across six stages of traffic, weather, and the long arm of the law. The lowest total hours wins; jail means you never finish at all.

## How to Run This Game

The complete rulebook is found at `references/GAME.md`. This single file is both the printable paper rulebook and the machine-readable spec—read it and run it as written.

To play, activate the engine skills against `references/GAME.md`:

- **`table`** — Set up and run a full session (with humans, AI seats, or both).
- **`gm`** — Referee: apply mechanics, restate the scoreboard, run the *Stage Weather* hook or its fallback.
- **`player`** — Fill a racer's seat with a persona.
- **`playtest`** — Run unattended AI-only rallies in batches for balance data.

Until those engine skills are available, the game is fully playable on paper: print `references/GAME.md`, grab pencils and one d6, and race.

## Table Needs

- 2–6 players, about an hour.
- One d6, a pencil, and paper for the scoreboard.
- Optional: a live weather forecast for the *Stage Weather* hook—the game plays differently in January than July. Offline tables roll the fallback.
