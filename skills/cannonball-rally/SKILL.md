# Cannonball Rally

An illegal coast-to-coast street race from New York City to Redondo Beach.
Racers pick a vehicle — ambulance, motorcycle, 4x4, SUV, supercar, or beige
sedan — and burn across six stages of traffic, weather, and the long arm of
the law. Lowest total hours wins; jail means you never finish at all.

## How to Run This Game

The complete rulebook is `references/GAME.md`. It is simultaneously the
printable paper rulebook and the machine-readable spec — read it and run it
as written; if it doesn't answer a question, the rulebook is incomplete and
that is a defect to report, not a gap to improvise over.

To play, activate the engine skills against `references/GAME.md`:

- **`table`** — set up and run a full session (humans, AI seats, or both).
- **`gm`** — referee: apply mechanics, restate the scoreboard, run the
  *Stage Weather* hook or its fallback.
- **`player`** — fill a racer's seat with a persona.
- **`playtest`** — run unattended AI-only rallies in batches for balance
  data.

Until those engine skills land, the game is fully playable on paper: print
`references/GAME.md`, grab pencils and one d6, and race.

## Table Needs

- 2–6 players, about an hour.
- One d6, pencil, and paper (scoreboard).
- Optional: a live weather forecast for the *Stage Weather* hook — the game
  plays differently in January than July. Offline tables roll the fallback.
